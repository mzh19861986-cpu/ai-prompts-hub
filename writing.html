# 5个高质量写作类AI提示词

---

## 1. 「反转开场」文章钩子生成器

**适用场景**：写公众号、小红书、知乎回答时，开头太平淡抓不住人，需要一个有冲击力的第一段。

**提示词模板**：

你是一位擅长写"黄金开头"的新媒体编辑。请为我写一个文章开头，要求：

【主题】：（填写你要写的主题）
【目标读者】：（例如：25-35岁职场人）
【发布平台】：（例如：公众号/小红书/知乎）
【情绪基调】：（例如：扎心/好奇/共鸣/反常识）

写作要求：
1. 第一句必须是一个"反常识断言"或"具体到细节的场景"，禁止用"在当今社会""随着...的发展"这类套话
2. 前3句内必须制造一个"认知缺口"（让读者觉得"啊？为什么？"）
3. 总字数控制在100-150字
4. 结尾留一个悬念，自然过渡到正文

请直接输出开头正文，不要解释。


**使用示例**：
> 主题：为什么越努力越焦虑 / 读者：28-35岁打工人 / 平台：公众号 / 基调：扎心
> 
> AI输出示例："我认识一个月薪3万的朋友，上周辞职了。理由不是累，是'我算了一下，再干10年也买不起现在租的这套房'。最可怕的不是这个数字，而是他说这话时，语气平静得像在报天气。"

## 2. 「逻辑骨架」长文大纲搭建器

**适用场景**：要写3000字以上的深度文章/报告，脑子里有素材但组织不起来，需要先搭骨架。

**提示词模板**：

你是一位结构化写作教练。我要写一篇长文，请帮我搭建大纲。

【核心论点】：（一句话说清你想证明什么）
【目标字数】：（例如：3000字）
【已有素材】：（罗列你手上的案例、数据、观点，没有就写"无"）
【读者已知】：（读者已经知道什么，避免重复）

请输出：
1. 一句话中心论点（提炼版）
2. 3-5个分论点，每个分论点必须满足：①能独立支撑中心论点 ②彼此不重叠 ③有递进或并列关系
3. 每个分论点下标注：需要什么类型的论据（数据/案例/类比/引用）
4. 标出最容易写崩的1个环节，并给出应对建议
5. 全文的"钩子-展开-高潮-收尾"节奏分配

用Markdown表格输出大纲，不要写成文章。


**使用示例**：
> 核心论点：远程办公不会成为主流，但会永久改变办公室的意义 / 字数：3500 / 素材：GitHub远程报告、马斯克推特、身边3个混合办公案例
> 
> AI会给出分论点表格，标注每个部分需要补充什么数据，并提醒"第3部分容易写成抱怨，建议用对比案例"。

## 3. 「去AI味」人味改写器

**适用场景**：AI写出来的段落读起来像说明书，需要改得像真人写的，有节奏、有情绪、有个人风格。

**提示词模板**：

你是一位文字"去工业化"专家。请把下面这段AI味很重的文字改成有人味的版本。

【原文】：（粘贴你的文字）
【想要的人设】：（例如：一个说话直接的资深程序员/一个爱吐槽的宝妈）
【目标平台】：（例如：即刻/微博/朋友圈）

改写规则：
1. 删掉所有"首先其次最后""综上所述""值得注意的是"这类连接词
2. 长句拆成短句，允许出现不完整句
3. 加入1-2个口语化表达或行业黑话（符合人设）
4. 允许出现1处"自我打断"（比如"——不对，应该说..."）
5. 保留原意，不改事实
6. 输出后附一句：我改了哪里（不超过3点）

直接输出改写后的文字。


**使用示例**：
> 原文："首先，远程办公提高了员工的工作效率。其次，它也降低了企业的办公成本。综上所述，远程办公具有诸多优势。"
> 
> 改写后："远程办公这事，效率是真高——至少不用把两小时耗在通勤上。老板也乐，工位租金省一大笔。当然，也不是没代价，这个后面说。"
